# القاضي الذكي لتصحيح الاختبارات

تطبيق Android مبني بـ Flutter، مستوحى من سير عمل تطبيقات OMR مثل EvalBee، بواجهة عربية واتجاه RTL.

## الإصدار التمهيدي 0.1
- واجهة عربية ولوحة رئيسية.
- إنشاء اختبار بعدد أسئلة من 1 إلى 200 وعدد خيارات من 2 إلى 5.
- شاشة إدخال مفتاح الإجابة.
- استيراد صورة ورقة الإجابة من الكاميرا أو المعرض.
- **لم يُنفذ بعد**: اكتشاف علامات OMR، احتساب الدرجات، إنشاء PDF لورقة الإجابة، حفظ البيانات الدائم، تصدير النتائج.

## إعداد وتشغيل Android
1. تثبيت Flutter SDK و Android Studio مع Android SDK.
2. تنفيذ `flutter pub get`.
3. إنشاء ملفات منصة Android القياسية: `flutter create --platforms=android .`.
4. تشغيل التطبيق: `flutter run`.

## خطة التنفيذ
1. تصميم ورقة OMR للطباعة بعلامات محاذاة ورقم نموذج.
2. إنشاء PDF للورقة ومفتاحها.
3. معالجة الصور محلياً: كشف الورقة وتصحيح المنظور وقراءة تعبئة الدوائر.
4. عرض الإجابات غير الواضحة للمراجعة قبل اعتماد الدرجات.
5. حفظ الاختبارات والنتائج محلياً وتصدير PDF/CSV.

لا تعتمد أي درجة آلياً قبل اختبار محرك القراءة على أوراق مطبوعة وصور كاميرا حقيقية. يجب تحويل الحالات الملتبسة إلى مراجعة بشرية.
