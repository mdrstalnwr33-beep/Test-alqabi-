# القاضي الذكي لتصحيح الاختبارات

تطبيق Android بواجهة عربية، مبني باستخدام Flutter، ويستهدف سير عمل تصحيح أوراق الاختيار من متعدد بطريقة OMR، مستلهماً الفكرة العامة من EvalBee.

## الوظائف الموجودة في فرع التطوير
- إنشاء اختبارات من 1 إلى 100 سؤال، وبعدد خيارات من 2 إلى 5.
- إعداد مفتاح الإجابة وحفظه محلياً على الجهاز.
- إنشاء ورقة إجابة A4 قابلة للمعاينة والطباعة بصيغة PDF.
- تصوير ورقة الطالب أو اختيار صورة من المعرض.
- تحديد زوايا الورقة الأربع يدوياً بالترتيب لتصحيح المنظور.
- تحليل تعبئة الدوائر محلياً، مع وضع العلامات غير الواضحة للمراجعة.
- إدخال اسم الطالب ومراجعة الإجابات قبل اعتماد الدرجة.
- حفظ النتائج محلياً، وتصدير تقرير PDF وملف CSV متوافق مع Excel.
- الوظائف الأساسية لا تحتاج إلى حساب فوترة أو خادم خارجي.

## سير الاستخدام
1. أنشئ اختباراً وحدد عدد الأسئلة والخيارات.
2. افتح الاختبار وحدد الإجابة الصحيحة لكل سؤال.
3. احفظ المفتاح ثم اطبع ورقة الإجابة من زر الطباعة.
4. وزّع الورقة المطبوعة على الطلاب.
5. من تبويب «التصحيح»، اختر الاختبار وصوّر الورقة كاملة.
6. المس زوايا الورقة الأربع بالترتيب الظاهر على الشاشة.
7. ابدأ التحليل، أدخل اسم الطالب، ثم راجع الاختيارات المقروءة.
8. اعتمد النتيجة، ثم افتح تبويب النتائج لتصدير PDF أو CSV.

## تشغيل المشروع محلياً
يتطلب Flutter SDK و Android Studio و Android SDK:
```bash
flutter create --platforms=android --org com.alqadi --project-name alqadi_smart_exam_checker --no-pub .
flutter pub get
flutter analyze
flutter test
flutter run
```

## بناء APK عبر GitHub Actions
كل تحديث على فرع `feature/flutter-omr-app` يشغّل فحص التحليل والاختبارات ثم يبني APK إصدارياً. بعد نجاح التشغيل، نزّل ملف APK من قسم Artifacts في تشغيل GitHub Actions.

## حدود الإصدار التجريبي
- تحديد زوايا الورقة يدوي وليس كشفاً تلقائياً لحواف الورقة.
- دقة قراءة العلامات تعتمد على جودة الطباعة والتصوير، وعدم وجود ظلال أو طيّات أو علامات مزدوجة.
- مراجعة الإجابات قبل اعتماد النتيجة مقصودة لتجنب احتساب درجات خاطئة.
- يجب إجراء اختبارات ميدانية على أوراق مطبوعة وصور من أجهزة Android مختلفة قبل استخدام النتائج كدرجات رسمية.
- البيانات محفوظة محلياً على الجهاز في هذا الإصدار؛ لا توجد مزامنة سحابية أو حسابات معلمين بعد.
